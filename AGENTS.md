# Instrucciones para Codex

- Lee primero README.md y el documento de alcance antes de cambiar código.
- Antes de implementar, resume el comportamiento esperado y los archivos que cambiarían.
- Mantén cada cambio acotado a una tarea.
- No agregues dependencias sin explicar por qué son necesarias.
- No añadas autenticación ni operaciones que modifiquen repositorios; este proyecto es de solo lectura.
- Añade pruebas para el comportamiento nuevo y usa respuestas simuladas: las pruebas no deben depender de GitHub ni de la red.
- No hagas commits sin que el usuario lo pida.
- Al terminar, resume los cambios, las verificaciones ejecutadas y las decisiones pendientes.
